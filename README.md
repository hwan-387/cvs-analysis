# 🏪 서울시 편의점 상권 분석

> **서울시 행정동별 상권·인구·편의점 데이터를 기반으로 신규 편의점 출점 후보지를 탐색하는 데이터 분석 대시보드**

서울시 행정동 단위의 편의점 분포와 **상주인구·직장인구·유동인구·1인 가구·상권 특성·경쟁 수준**을 종합적으로 분석하여, 신규 편의점 출점 시 우선적으로 검토할 지역을 데이터 기반으로 스크리닝하는 프로젝트입니다.

---

## 🎯 Project Overview

편의점 신규 출점은 단순히 **편의점이 적은 지역**을 찾는 것만으로 판단하기 어렵습니다.

본 프로젝트에서는 다음과 같은 질문에서 출발했습니다.

* 어떤 지역에 편의점 수요가 충분한가?
* 현재 편의점 경쟁 수준은 어느 정도인가?
* 최근 편의점 점포 수는 증가하고 있는가?
* 상주인구뿐 아니라 실제 활동인구는 얼마나 되는가?
* 여러 지표를 종합했을 때 **신규 출점 후보지로 우선 검토할 지역은 어디인가?**

이를 해결하기 위해 행정동 단위 데이터를 통합하고, **상권 특성 및 경쟁 수준 분석 → 후보지 스크리닝 → 지도 기반 시각화**까지 하나의 대시보드로 구현했습니다.

---

## 💡 Key Features

### 1. 서울시 편의점 시장 현황

* 2023~2025년 편의점 점포 수 분석
* 서울시 전체 편의점 규모 및 3개년 증감 분석
* 행정동별 평균 편의점 수 산출
* 편의점 분포가 높은 지역 탐색

### 2. 행정동 단위 상권 분석

행정동별 다음 지표를 비교합니다.

* 편의점 점포 수
* 상주인구
* 직장인구
* 유동인구
* 활동인구
* 1인 가구 비중
* 직장인구 / 상주인구
* 유동인구 / 상주인구
* 상권 특성
* 경쟁 수준

이를 통해 단순한 점포 수 비교를 넘어 **지역별 소비 수요와 상권 구조를 함께 분석**했습니다.

### 3. GIS 기반 공간 분석

행정동 GeoJSON 데이터와 편의점 데이터를 결합하여 서울시 편의점 분포를 지도상에 표현합니다.

* 행정동별 편의점 분포 시각화
* 특정 행정동 선택 및 강조
* 지역별 편의점 밀집 수준 비교
* 상권 분석 결과의 공간적 이해 지원

### 4. 출점 후보지 스크리닝

신규 출점 가능성이 높은 지역을 빠르게 탐색할 수 있도록 **후보점수(0~3점)** 기반의 1차 스크리닝 로직을 적용했습니다.

후보점수는 다음 3가지 조건을 기반으로 산정합니다.

| 평가 요소       | 목적               |
| ----------- | ---------------- |
| 점포 밀도·경쟁 여건 | 기존 경쟁 수준 파악      |
| 최근 3년 점포 변화 | 시장 성장·변화 방향 확인   |
| 활동인구 수요     | 잠재적인 소비 수요 규모 확인 |

각 조건을 만족할 경우 1점을 부여하여 **최대 3점**으로 후보지를 평가합니다.

후보지는 후보점수와 활동인구를 기준으로 정렬하여 우선 검토 지역을 확인할 수 있습니다.

### 5. Interactive Dashboard

사용자가 직접 조건을 변경하면서 분석할 수 있도록 Streamlit 기반 대시보드를 구현했습니다.

* 자치구 필터
* 행정동 선택
* 상권 특성 필터
* 경쟁 수준 필터
* 최소 활동인구 설정
* 최소 후보점수 설정
* 조건에 따른 분석 결과 실시간 갱신

### 6. 분석 리포트 생성

현재 설정한 분석 조건을 기반으로 요약 리포트를 자동 생성합니다.

* 분석 조건
* 서울시 편의점 현황
* 분석 대상 지역 수
* 창업 후보지 수
* 최우선 후보지
* 후보점수

분석 결과를 `.txt` 파일로 다운로드할 수 있도록 구현했습니다.

## 🔍 Portfolio Highlights

### 데이터 통합

서로 다른 형태의 지역 데이터를 행정동 기준으로 통합하여 **편의점 시장 규모와 지역 수요를 함께 분석**했습니다.

### 지표 설계

단순히 `편의점 수`를 비교하지 않고,

**상주인구 → 직장인구 → 유동인구 → 활동인구 → 경쟁 수준 → 최근 점포 변화**

를 함께 고려하여 출점 후보지를 평가하도록 분석 기준을 설계했습니다.

### 공간 데이터 활용

GeoPandas를 활용해 행정동 공간 데이터를 결합하고, 편의점 분포를 지도 형태로 시각화하여 **데이터의 공간적 패턴을 직관적으로 확인**할 수 있도록 구현했습니다.

### 데이터 기반 의사결정

분석 결과를 단순 통계에 그치지 않고 **출점 후보점수와 후보지역 리스트**로 연결하여 실제 비즈니스 의사결정에 활용할 수 있는 형태로 구성했습니다.

### 분석 결과의 서비스화

Jupyter Notebook에서 수행한 분석을 Streamlit 대시보드로 확장하여 사용자가 직접 필터를 조정하고 결과를 탐색할 수 있도록 구현했습니다.

## 📌 Limitations

본 프로젝트의 결과는 **행정동 단위 데이터를 활용한 1차 출점 후보지 스크리닝**입니다.

실제 출점 의사결정에는 추가적으로 다음 요소를 고려할 필요가 있습니다.

* 개별 점포 단위 경쟁점 위치
* 실제 유동 동선
* 임대료 및 보증금
* 점포 접근성 및 가시성
* 주변 시설 및 상권 변화
* 시간대별 유동인구
* 예상 매출 및 운영 비용

따라서 본 분석은 최종 입지를 결정하기 위한 모델이 아니라 **후보지역을 데이터 기반으로 좁히기 위한 분석 도구**로 활용하는 것을 목적으로 합니다.
